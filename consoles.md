# Plataformes i consoles on jugar a Pac-Man

- **Arcade:** màquina recreativa original de Pac-Man, publicada el 1980.
- **Atari 2600:** una de les primeres adaptacions per a consoles domèstiques.
- **Atari 5200:** versió domèstica del joc.
- **Nintendo Entertainment System (NES):** versió per a la consola de Nintendo.
- **Game Boy:** adaptacions portàtils de Pac-Man.
- **Super Nintendo (SNES):** versions i recopilatoris relacionats amb Pac-Man.
- **PlayStation:** recopilatoris de jocs clàssics de Pac-Man.
- **Ordinadors personals:** versions per a diferents sistemes operatius.
- **Navegadors web:** versions en línia que permeten jugar sense instal·lar el joc.
- **Telèfons mòbils:** adaptacions per a Android i iOS.
